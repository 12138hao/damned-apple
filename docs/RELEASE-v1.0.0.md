# 该死的苹果 v1.0.0

第一个完整版本：**四章流程全部可玩**，四个 Boss、结局演出、全流程音效与配乐。

## 本版包含

- **四章地图**：主城 → 地下 → 丛林 → 伊甸园（含主城屋内、岩屋、林中屋三个室内场景）
- **四个 Boss**，各有独立的招式与战场机制：
  - 大苹果：双血量阶段、跳跃砸地、吐毒，被打哭后地板塌陷
  - 野兽苹果：冲撞、带地面预警的扑击、吐毒球、落地震波
  - 苹果仙子：悬浮飞行、蓄力泪光束、分裂出会同步出手的分身
  - 黑蛇：吐毒铺池、甩尾横扫（12 帧动画 + 整侧危险带）、震落三波苹果、召唤蛇小怪、半血狂暴
- **完整结局**：奶蛙对话 → 缓慢黑屏 → 制作名单滚动 → 回主菜单。通关后点「继续游戏」会提示「游戏已通关，继续游戏则开启新游戏」
- **存档系统**：存档点、跨场景复活、通关标记持久化
- **武器系统**：木棒 / 尺子（蓄力近战，20~60 随蓄力递增）、粉笔（远程投射物，50/发）
- **探索要素**：可攀爬藤蔓、泥潭减速、单向平台下穿、载具、古井转场演出
- 音效 36 个、背景音乐 11 首

## 操作

| 按键 | 动作 |
|---|---|
| `A` / `D` | 左右移动 |
| `W` / `S` | 上瞄 / 下蹲（单向平台下穿） |
| `空格` | 跳跃（按住跳得更高） |
| `鼠标左键` | 攻击（360° 跟随鼠标，按住蓄力） |
| `1` `2` `3` `4` | 切换武器槽 |
| `E` | 对话 / 存档 / 拾取 / 进出屋 |
| `R` | 上 / 下车 |
| `W`（藤蔓旁） | 抓住藤蔓上爬，跳跃键蹬开 |

## 运行

解压后双击 `该死的苹果.exe`。

> **必须保留整个文件夹**——`data_MyGame_windows_x86_64/` 是 .NET 程序集，只把 exe 拖出来会打不开。

不需要安装 Godot，也不需要装 .NET 运行时。Windows 可能弹出 SmartScreen 蓝色提示（exe 没有代码签名），点「更多信息 → 仍要运行」即可。

## 系统要求

- Windows 10 / 11，x64
- 约 350 MB 磁盘空间

## 从 v0.1.0 以来的变化

v0.1.0（2026-10-27）只包含第一关和它的 Boss。这一版补齐了：

- 第二关「地下」：野兽苹果 Boss、恐怖苹果、绳索攀爬、移动平台、岩屋
- 第三关「丛林」：泥潭、可攀爬藤蔓、海盗苹果与骷髅苹果、苹果仙子 Boss、林中屋、古井转场
- 第四章「伊甸园」：黑蛇 Boss 与四个技能、召唤物、结局演出、通关状态
- 武器伤害与空手拳改为全局资源（改一处全地图生效）
- 大量判定与手感修复：小怪碰撞体按帧跟随美术、粉笔取最近敌人结算、Boss 死亡后镜头归位、甩尾提速到 0.45 秒
