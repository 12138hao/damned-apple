# 该死的苹果 v1.0.1

## 本版修改

**载具子弹伤害统一为 25。**

此前六张地图各自配置这一个数值，导致同一辆车在不同地图手感完全不同：

| 地图 | 原值 |
|---|---|
| 主城 / 地下 / 丛林 | 15 |
| 伊甸园 | 20 |
| 主城屋内 / 岩屋 | 30 |

现在改为共用 `Box.VehicleBulletDamage` 的默认值 **25**，场景不再覆盖——以后要调，改一处就全地图生效，不会再出现「只改了这张图」的问题。

## 说明

功能与 v1.0.0 完全一致，只有这一项数值调整。**首次游玩直接下这个版本即可。**
